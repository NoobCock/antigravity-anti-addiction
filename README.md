## 安装

Windows PowerShell 一键安装：

```powershell
irm https://raw.githubusercontent.com/NoobCock/antigravity-anti-addiction/main/install.ps1 | iex
```

或克隆仓库后本地安装：

```powershell
git clone https://github.com/NoobCock/antigravity-anti-addiction.git
cd antigravity-anti-addiction
.\install.ps1
```
